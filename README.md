# PAYROLL-SYSTEM
A simple payroll  system created with C++
In this assignment, I designed and implemented a small C++ console program that models a simplified employee payroll system.

The main focus for me was to show that I can apply conditional logic, using if, else if, and switch statements, together with a for loop, to solve a realistic problem. I also had to make sure that I used variables and data types correctly throughout the program.

In my program, I used a for loop to process multiple employees one after the other. For each employee, I captured their name, hours worked, hourly rate, and department. I then used if / else if statements to calculate overtime pay and to determine which tax bracket the employee falls into. I used a switch statement to assign a department allowance and to provide an exit option in the main menu.

Through this assignment, I was able to demonstrate how conditional logic and loops can be combined to create a working payroll system that calculates gross pay, tax deductions, allowances, and net pay accurately.
